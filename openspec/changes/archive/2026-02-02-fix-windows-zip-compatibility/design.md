
# Design: Windows ZIP Compatibility (Final Revision)

## 1. Conclusion
The root cause of the ZIP incompatibility was **not** `electron-builder`'s compression method, but rather **path lengths exceeding Windows limits** caused by including Android build artifacts (`@capacitor/android`, `@capacitor/camera`) in the Windows release.
After moving these dependencies to `devDependencies`, the content is clean (~150MB).

## 2. Final Strategy: Restore Standard Tooling
Since the content is fixed, we can remove the complex custom zipping script (`archiver`) and return to using `electron-builder`'s native capabilities. This simplifies the build pipeline.

## 3. Configuration Changes
### package.json
1.  **Revert** `build.win.target` to `zip` (or `nsis` + `zip`, etc.).
2.  **Remove** `archiver` dependency.
3.  **Restore** `electron:build` script to just `electron-builder` (remove `node scripts/pack-windows-zip.cjs`).

### Cleanup
- Delete `scripts/pack-windows-zip.cjs`.

## 4. Verification
- Run `npm run electron:build`.
- Verify `release/Just Scales-1.3.1-win.zip` (auto-generated by builder) exists and works.
